# Momken Design System

A reusable Android design system for mobility and ride-sharing products, built with Kotlin, Jetpack Compose and Material 3.

## Modules

- `designsystem` — design tokens, light/dark themes and reusable UI components.
- `app` — a small showcase application for previewing the design system.

## Requirements

- Android Studio with a compatible Android Gradle Plugin
- JDK 17
- Android SDK 36

## Getting started

Open the project in Android Studio and sync Gradle. Run the `app` configuration on an emulator or Android device.

## Design principles

- Reusable components with clear APIs
- Material 3 foundations and semantic color roles
- Responsive Compose layouts
- Accessibility-friendly controls
- Arabic/RTL-ready layout direction
- No ride-booking or backend business logic inside the design-system module

## Package

`com.momken.designsystem`

## Status

Initial project scaffold. Component APIs and visual tokens will evolve as the library is implemented.
